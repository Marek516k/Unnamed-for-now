# Unnamed-for-now
A roguelike RPG game prototype using LÖVE 2D.

## Game Features

### Player
- Move left/right (A/D keys)
- Jump with momentum (W key)
- Attack with sword (Left mouse button)
- Health system (nice try)
- dashing (soon)

### Enemy
- Follows player (yea thats about it)
- Avoids falling off platforms (if it doesnt bug tru)
- "Intelligent" jumping to reach player
- (tries to) Attacks when in range

### Combat
- Weapon collision detection (somehow not broken)
- Damage system (also broken)
- Enemy attack patterns (not yet)
